تحديث منظومة السلامة — النسخة 5.5.5

1) فك ضغط الحزمة.
2) انسخ index.html و forms2.json و CHANGELOG.md إلى جذر مستودع hse-manzoma.github.io ووافق على استبدالها.
3) افتح GitHub Desktop وراجع التغييرات، ثم أنشئ commit وارفعه إلى GitHub.
4) بعد اكتمال النشر، حدّث الموقع تحديثًا قويًا (Ctrl+F5) وتأكد أن رقم النسخة صار 5.5.5.

تتضمن الحزمة إصلاح إشعارات مهام فحص المعدات، وضبط إدخال KPI بحيث يسجل المستخدم لنفسه تلقائيًا، والأدمن فقط يختار المدخل والموظف. كما تتضمن إصلاح أنواع طلبات الإجازة/الإذن/المأمورية/التكليف والتوقيع الحي.
