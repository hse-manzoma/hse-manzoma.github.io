تحديث منظومة السلامة — النسخة 5.5.24

1) فك ضغط الحزمة في مجلد مؤقت.
2) انسخ ملفات الحزمة إلى جذر مستودع hse-manzoma.github.io ووافق على استبدال الملفات عند الطلب. ارفع مجلد form-specs كاملًا وملف forms-index.json مع index.html وsw.js وملفات الصور. لا تحذف مجلد .git.
3) من GitHub Desktop راجع الملفات، ثم أنشئ commit وارفع التغيير.
4) بعد اكتمال النشر افتح الموقع واضغط Ctrl+F5. قائمة النماذج أصبحت خفيفة؛ أول فتح لأي نموذج ينزّل ملفه وخلفيته، وبعد ذلك يستخدم الجهاز الملفات المخزنة لتسريع فتحها.

تعرض قائمة الحوادث نوع الإصابة والمصاب وكاتب التقرير وحالة توقيع الكاتب والمعتمد. تظهر شارة «معتمد» عند وجود مراجعة فعلية للسجل مع اسم المعتمد.

أضيف أرشيف اجتماعات السلامة في صفحة «مكتب السلامة». سجّل موضوع الاجتماع وتاريخه ومكانه والحضور والقرارات، ثم افتح «مرفقات» لرفع محضر PDF أو الصور والمستندات. استخدم مربع البحث للتصفية بالموضوع أو التاريخ أو المكان أو الحضور.

لم يتم تغيير إعدادات قاعدة البيانات أو شكلها. سجلات الاجتماعات الجديدة تُحفظ ضمن بيانات مكتب السلامة الحالية.
