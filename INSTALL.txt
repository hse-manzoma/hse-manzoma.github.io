تحديث التوقيع الحي — النسخة 5.5.1

1) فك ضغط هذا المجلد.
2) انسخ index.html و forms2.json و CHANGELOG.md إلى جذر مستودع hse-manzoma.github.io، ووافق على استبدال الملفات الثلاثة.
3) افتح GitHub Desktop، راجع الملفات المتغيرة، ثم أنشئ commit وارفعه.
4) بعد ظهور النشر، حدّث الموقع تحديثًا قويًا (Ctrl+F5).

التوقيع يُرسم مباشرة وقت التوقيع. هذا التحديث لا يغيّر إعدادات GitHub أو قاعدة البيانات؛ بيانات التوقيع الجديدة تُحفظ مع سجل الفحص/المأمورية داخل المنظومة عند اعتماد المستخدم.
