تحديث منظومة السلامة — النسخة 5.5.7

1) فك ضغط الحزمة.
2) انسخ index.html و forms2.json و CHANGELOG.md إلى جذر مستودع hse-manzoma.github.io ووافق على استبدالها.
3) افتح GitHub Desktop وراجع التغييرات، ثم أنشئ commit وارفعه.
4) بعد اكتمال النشر، حدّث الموقع بـ Ctrl+F5 وتأكد من ظهور v5.5.7.

بحث المعدات يشمل الرقم أو المكان أو حالة الفحص أو شهره أو نوع المعدة أو سعتها أو اسم الفاحص. الحزمة تضم أيضًا إصلاحات المهام وKPI والطلبات والتوقيع الحي السابقة.
