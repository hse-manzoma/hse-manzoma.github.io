تحديث منظومة السلامة — النسخة 5.5.3

1) فك ضغط الحزمة.
2) انسخ index.html و forms2.json و CHANGELOG.md إلى جذر مستودع hse-manzoma.github.io ووافق على استبدالها.
3) افتح GitHub Desktop وراجع التغييرات، ثم أنشئ commit وارفعه إلى GitHub.
4) بعد اكتمال النشر، حدّث الموقع تحديثًا قويًا (Ctrl+F5).

إصلاح حفظ طلبات إذن الساعتين والمأمورية الخارجية والتكليف الإضافي: أصبحت تُحفظ في مجموعة طلبات الإجازة الموجودة لتوافق صلاحيات قاعدة البيانات الحالية، مع بقاء الموافقة الإدارية قبل إنشاء السجل الرسمي. تتضمن الحزمة أيضًا تحديث التوقيع الحي السابق.
