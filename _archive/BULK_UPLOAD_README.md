## 🚀 كيفية الاستخدام

### من الواجهة:
1. ادخل كمدير (Admin)
2. اذهب إلى **ملفي** (My Profile)
3. اضغط **📥 رفع بيانات ورقية**
4. اختر ملف `incidents_data.json`
5. اختر نوع البيانات (Incident)
6. فعّل "التحديث التلقائي للإحصائيات" ✓
7. اضغط **رفع البيانات**
